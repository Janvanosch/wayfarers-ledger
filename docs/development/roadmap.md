# Development Roadmap

**Status:** Active

---

# Purpose

The roadmap describes the major phases of development for The Wayfarer's Ledger.

Unlike the backlog, the roadmap focuses on *when* major capabilities are expected to be built rather than *what* individual features exist.

The roadmap may evolve as the project grows.

---

# Phase 1 — Foundation

## Goal

Build a stable foundation for long-term development.

### Includes

- Project Bible
- Documentation
- Design System
- Core Layout
- Routing
- SQLite Integration
- Local Vault
- Reusable Components

**Target Version:** v0.1.x

---

# Phase 2 — Core Journey

## Goal

Allow a Wayfarer to start recording memories.

### Includes

- Home Dashboard
- Gear Library
- Outfit Library
- Festival Library
- Journal Entries
- Timeline
- Basic Search

**Target Version:** v0.2.x

---

# Phase 3 — Rich Memories

## Goal

Connect memories into meaningful stories.

### Includes

- Experience Notes
- Maintenance
- Photos
- Galleries
- Makers
- Wishlist
- Timeline Improvements

**Target Version:** v0.3.x

---

# Phase 4 — Intelligent Assistance

## Goal

Reduce manual work without sacrificing ownership.

### Includes

- AI Recognition
- Maker Suggestions
- Metadata Extraction
- Smart Search
- AI-assisted Capture

**Target Version:** v0.4.x

---

# Phase 5 — Polish

## Goal

Refine the complete experience.

### Includes

- Performance Improvements
- Accessibility
- Animations
- Import & Export
- Backup Improvements
- Final UI Polish

**Target Version:** v1.0

---

# Beyond Version 1.0

Possible future directions include:

- Mobile Companion
- Optional Cloud Sync
- Plugin System
- Multiple Ledgers
- Community Templates

These ideas are intentionally outside the scope of Version 1.

---

# Notes

The roadmap defines direction, not deadlines.

Quality takes priority over speed.

A delayed feature is preferable to a rushed implementation.
