# Product Backlog

**Status:** Active

# Purpose

The Product Backlog contains every planned feature for The Wayfarer's Ledger.

This document represents the long-term scope of the project.

Features move from the backlog to a milestone when active development begins.

The backlog is intentionally organised by functional area rather than priority.
