# The Wayfarer's Ledger

> *A personal companion for fantasy festivals.*

The Wayfarer's Ledger is an offline-first application designed for fantasy festival enthusiasts.

It helps Wayfarers prepare for events, manage their gear, document their journeys and preserve the memories that make every festival unique.

Rather than scattering information across notebooks, spreadsheets, packing lists and bookmarks, the Ledger brings everything together in one place.

Its purpose is simple:

> **Capture quickly. Remember forever.**

---

# Philosophy

The Wayfarer's Ledger is built around the idea that festivals are more than events—they are journeys.

Every outfit tells a story.

Every piece of gear has a history.

Every festival becomes a memory worth preserving.

The Ledger is intentionally personal.

It is **not**:

- a social network
- a marketplace
- an inventory system
- a productivity tool
- a game

It exists for one person.

**The Wayfarer.**

---

# Core Principles

The project follows six guiding principles.

- Offline First
- Privacy First
- Local Ownership
- Progressive Completion
- Open Standards
- Long-Term Preservation

Technology should support the Journey.

Never define it.

# Getting Started

Clone the repository.

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

Build for production.

```bash
npm run build
```

---

# Development Workflow

Development follows a documentation-first workflow.

1. Read the Keeper Log.
2. Review the Current Milestone.
3. Consult the Project Bible when making architectural decisions.
4. Implement the next milestone task.
5. Update documentation when appropriate.
6. Commit meaningful progress.

The Project Bible is always considered the source of truth.
