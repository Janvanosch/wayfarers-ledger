# The Wayfarer's Ledger

> A practical handbook for fantasy festivals.

---

## Overview

The Wayfarer's Ledger is an offline-first web application designed to help visitors prepare for fantasy festivals.

Instead of scattering information across notebooks, spreadsheets, packing lists and bookmarks, the Ledger brings everything together in one place.

The long-term goal is to create a reliable companion for festival visitors before, during and after an event.

---

## Planned Features

- Equipment database
- Packing lists
- Festival information
- Character & costume inspiration
- Camp planning
- Shopping lists
- Offline access
- Personal notes
